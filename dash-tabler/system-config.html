Tổng quan

Các giá trị dưới đây áp dụng cho toàn bộ hệ thống, mọi tenant. Sửa sai có thể làm gián đoạn chatbot/đăng bài của tất cả khách hàng.

AnythingLLM

Cần bạn tự điền — đây là Cloudflare secret, tôi chưa từng thấy giá trị cũ nên không điền sẵn được. Nhớ có dấu / ở cuối, đúng như code đang ghép chuỗi.
Cần bạn tự điền — lấy trong giao diện admin của AnythingLLM (VPS mới).

Telegram

Cần bạn tự điền — lấy lại từ @BotFather trên Telegram nếu không nhớ token cũ.

Cloudinary (chèn logo/chữ lên ảnh)

Cấu hình 1 lần cho cả hệ thống. Từng workspace chỉ cần bật/tắt logo, chữ và chọn vị trí trong trang Cấu hình. Lấy ở cloudinary.com/console → Dashboard.

Gemini (tạo nội dung)

Dùng để viết nội dung và dịch trong Content Planning. Khi để trống, hệ thống dùng OpenAI như trước.

OpenAI (vẽ ảnh)

Cần bạn tự điền — Cloudflare secret, không đọc lại được giá trị cũ.

PixVerse (tạo video)

Khoá Platform API cho media trong bài viết. PixVerse text-to-video dùng khoá này; ảnh prompt tiếp tục dùng OpenAI vì Platform API hiện chỉ hỗ trợ ảnh theo template.

Gọi thoại AI (STT/TTS)

Chỉ cần điền nếu chọn Deepgram ở trên.

Vận hành

Đồng bộ lại AnythingLLM (khi đổi VPS mới hoặc đổi embedding model)
Đẩy lại system_prompt + embed lại toàn bộ tài liệu RAG của MỌI tenant vào ANYTHINGLLM_URL hiện tại. Chạy lần lượt từng tenant, giữ trang mở tới khi xong. Lưu cấu hình ở trên trước khi bấm.
PB_URL, PB_ADMIN_EMAIL, PB_ADMIN_PASS KHÔNG quản lý ở đây — đó là thứ worker cần để tự kết nối vào PocketBase, đưa vào đây sẽ thành vòng lặp con gà quả trứng. Vẫn phải set qua wrangler secret put.

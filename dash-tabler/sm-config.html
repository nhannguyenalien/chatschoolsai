Kết nối YouTube
Chuẩn bị một lần trên Google Cloud (console.cloud.google.com)
  1. Tạo project → bật YouTube Data API v3.
  2. Màn hình đồng ý OAuth: loại External, thêm email của bạn vào Test users (nếu app còn ở chế độ Testing).
  3. Credentials → tạo OAuth client ID loại Web application, thêm Authorized redirect URI:
  4. Dán Client ID và Client Secret vào ô bên dưới rồi bấm tiếp tục để đăng nhập Google.
Dự án Google chưa qua kiểm tra API thì YouTube tự khoá video ở riêng tư — xem hướng dẫn xác minh.

Page / Account / Kênh chat
Áp dụng cho Facebook/Instagram/LinkedIn. "Dịch" tự dịch ngay trước khi đăng; "Bài riêng" tạo một bài khác nhau cho mỗi kênh từ cùng nguồn tin.
Dùng cho các field đặc thù của từng platform (app secret, verify token, webhook...).

Kết nối WhatsApp Cloud API (AI tự trả lời)

  1. Phone Number ID (ô ID kênh) và Access Token: Meta for Developers → App → WhatsApp → API Setup. Token tạm chỉ sống 24 giờ — dùng thật thì tạo token vĩnh viễn từ System User trong Business Settings.
  2. Điền app_secret (App settings → Basic) và bấm "Tạo Verify Token ngẫu nhiên" trong ô Cấu hình thêm, rồi Lưu.
  3. Meta App Dashboard → WhatsApp → Configuration → Webhook: Callback URL https://apic.schoolsai.work/meta-webhook, dán đúng Verify Token → Verify and save, rồi Subscribe field messages.
  4. Khách nhắn tới số WhatsApp thì AI tự trả lời trong cửa sổ 24 giờ kể từ tin của khách. Số test miễn phí chỉ nhắn được tới tối đa 5 số đã thêm vào danh sách người nhận.

Kết nối nhắn tin/bình luận tự động (Messenger & Instagram)

  1. Bấm nút "Tạo Verify Token ngẫu nhiên" ở trên (hoặc tự nghĩ 1 chuỗi bất kỳ), rồi bấm Lưu kênh này lại.
  2. Vào Meta App Dashboard của bạn → Webhooks → đăng ký: Callback URL https://apic.schoolsai.work/meta-webhook, dán đúng Verify Token vừa tạo.
  3. Subscribe field messages (nhắn tin riêng) và feed (Facebook)/comments (Instagram) nếu muốn tự động trả lời bình luận.
  4. Nếu App của bạn chưa qua App Review cho pages_messaging/pages_manage_engagement, chỉ tài khoản admin/tester của App nhận được tin nhắn/bình luận thật khi test.
